# MediaPipe Python Starter

This project is ready to run after download on Windows.

## Quick start

1. Download/clone the repository.
2. Double-click **`launch.bat`**

The launcher will:
- create `.venv` automatically (first run),
- install the latest dependencies from `requirements.txt`,
- start the Python program.

## Manual run (optional)

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python gaze_media_controller.py
# démo mains seule : python app.py```
